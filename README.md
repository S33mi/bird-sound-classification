# Bird Sound Classification

Audio classification of bird species using deep learning on spectrograms.

## Project Overview
- Dataset: BirdCLEF/ Kaggle Bird Song Sound data / xeno-canto subset / Huggingface ESC-50 Dataset (Birds Sound)
- Approach: MFCCs + CNN (or transfer learning with EfficientNet/ResNet)
- Goal: Build a practical bioacoustics classifier

## Notebooks
- `bird_sound_classification.ipynb` → EDA, preprocessing, CNN model, evaluation

## Technologies
Python · Librosa · TensorFlow/Keras · Scikit-learn · Matplotlib
